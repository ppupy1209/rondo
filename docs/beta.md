# Rondo 0.12 외부 베타

0.12의 목적은 기능 수가 아니라 일주일 동안 실제 작업을 맡겨도 복구 가능하고 지원 가능한지 확인하는 것입니다. 자동 텔레메트리나 자동 업로드는 추가하지 않습니다.

## 참여 방법

1. 한 줄 설치 후 실제 Git 저장소에서 평소처럼 `rondo`를 사용합니다.
2. 최소 세 번의 작업에서 Command Center 첫 권장 작업이 적절했는지 기록합니다.
3. 터미널 종료·재부팅 뒤 재접속, `rondo update --check`, 가능하면 `rondo rollback`을 한 번 확인합니다.
4. 문제가 생기면 `rondo support-bundle`을 만들고 `report.json`을 직접 확인한 뒤 issue에 첨부합니다. 묶음은 자동 전송되지 않습니다.

## 확인할 지표

| 지표 | 4점 기준 |
|---|---|
| 최초 설치 후 첫 세션까지 | 5분 이내, 문서 외 도움 없이 성공 |
| 다음 작업 추천 | 실제 다음 행동과 80% 이상 일치 |
| 종료·재부팅 후 복구 | 데이터 손실 없이 10회 중 10회 재접속 |
| 업데이트 또는 롤백 | 실패 시 기존 버전으로 돌아가며 launcher가 깨지지 않음 |
| 독립 테스트 | 구현 세션이 검증자로 재사용되는 사례 0건 |
| 지원 가능성 | 지원 묶음만으로 OS·버전·상태 범주를 확인 가능 |

## 제보 원칙

- 기능 오류는 GitHub issue, 취약점은 `SECURITY.md`의 비공개 경로를 사용합니다.
- 공급자 대화, 소스 코드, 비밀값, 전체 화면 캡처는 기본 첨부하지 않습니다.
- 재현에 원문이 꼭 필요하면 최소 예제로 바꾸고 어떤 데이터인지 명시합니다.
